# riftleaf

Rift timestamps and leaf durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/riftleaf/

## Install / run

```bash
git clone https://github.com/theworker02/riftleaf.git
cd riftleaf
node src/cli.js
node --test
```
